# MyPortfolio

Personal portfolio website of **Tarun Kumar Pardeshi** — Cloud & DevOps Engineer based in Canada.

## About

A responsive single-page portfolio showcasing professional experience, technical skills, certifications, projects, and contact information. Built with a modern, interactive design including an animated splash screen.

## Tech Stack

- **HTML5** — semantic markup
- **Tailwind CSS** (via CDN) — utility-first styling
- **JavaScript** — interactivity (splash screen, mobile menu, scroll progress)
- **Font Awesome 6** — icons
- **Google Fonts** (Poppins) — typography

## Structure

- `index.html` — the complete portfolio site (single file)
- `111.jpg` — profile/portrait image asset

## Viewing

Open `index.html` directly in a browser, or serve it locally:

```bash
cd MyPortfolio
python3 -m http.server 8000
# then open http://localhost:8000
```

## Sections

- Hero / About — headline, summary, and call-to-action
- Experience — Concentrix (Canada) and Drive-Sec Technologies roles
- Skills — Cloud, DevOps, networking, and tooling
- Projects — Agentic AI pipeline, cloud monitoring automation, cost optimization dashboard
- Education & Certifications — AWS certs, CCNA, postgraduate certificates
- Contact — email, LinkedIn, phone
